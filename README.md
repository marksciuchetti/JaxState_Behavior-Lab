# iMotions Workshop Series

Student workshops for the Martin's Family Clothing Consumer Behavior Research Laboratory (Jacksonville State University). Published with GitHub Pages from the main branch.

- index.html: the workshop list (site home page)
- workshops/: one self contained HTML page per workshop
- manuals/: downloaded iMotions help articles shared with the class (added as workshops are published)
- assets/: narration audio, screenshots, and videos used by the workshops

Open index.html locally to preview, or visit the GitHub Pages address for this repository.
