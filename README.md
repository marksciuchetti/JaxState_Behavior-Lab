# iMotions Workshop Series

Student workshops for the Martin's Family Clothing Consumer Behavior Research Laboratory (Jacksonville State University). Published with GitHub Pages from the main branch.

- index.html: the workshop list (site home page)
- workshops/: one self contained HTML page per workshop (Workshop 1: From Question to Publication with the Neon Glasses; Workshop 2: From Question to Publication with the Aurora)
- assets/ws1/, assets/ws2/: each workshop's figures (figures/, figures/live/), SIMULATED data files and analysis scripts (data/, data-figures/), and recorded narration (audio/, one MP3 per section plus cues.json)
- manuals/: downloaded iMotions help center articles the workshops cite, shared with the class with the permission of iMotions A/S (manuals/index.html lists them)

Open index.html locally to preview, or visit the GitHub Pages address for this repository. Figures from the iMotions manuals are used with permission for the lab course and are not to be redistributed.
