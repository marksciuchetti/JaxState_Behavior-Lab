# Manuals

Downloaded copies of the iMotions Help Center articles and guides that the workshops cite. The help center itself (help.imotions.com) requires a sign in through my.imotions.com; these copies are shared with the Jacksonville State University lab course with the permission of iMotions A/S. They are for class use and are not to be redistributed.

Every workshop links to the article it needs from its Resources section. The files are named after the help center page titles.
